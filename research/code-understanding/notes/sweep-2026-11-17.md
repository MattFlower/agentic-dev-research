## Findings

### A. DeltaDB — #5 and #6

- **What.** [DeltaDB](https://delta.dev/deltadb), by Zed / Delta. The page says "The version control
  system that records every edit with the conversation behind it." Each edit, a person's or an
  agent's, is a delta with an author and a base version. Messages and comments are deltas in the
  same history, so "From the code, you can get back to the conversation behind it." Rewind to any
  message. Teammates can read the conversation and comment before commit. Git stays for commits and
  pull requests. Built on CRDTs.
- **X, 2026-11-13.** [post](https://x.com/zeddotdev/status/2121317002803589376). "Attribution doesn't
  stop at the line. Turn on highlights to see which threads and commits wrote each part of it."
  Likes 207, bookmarks 34, reposts 3, impressions 8,636.
- **X, 2026-11-16.** [post](https://x.com/zeddotdev/status/2122445554865070376). Links DeltaDB and
  quotes the comprehension-debt post below. Likes 338, bookmarks 444, reposts 5, replies 10,
  impressions 69,940. Bookmarks are above likes.
- **X, 2026-11-14.** [post](https://x.com/zeddotdev/status/2121650009158435324). "Agent archaeology":
  piecing together why a teammate and their agent wrote code a certain way. Likes 70, bookmarks 26.
  Talk by Richard Feldman: [YouTube](https://www.youtube.com/watch?v=Enn9dVrRXAo).
- **Pushback.** Replies, low engagement.
  [kalminium](https://x.com/kalminium/status/2122598441977339944) ("It's not about keeping track of
  what changed", 2 likes) and
  [atticus_indica](https://x.com/atticus_indica/status/2122659443913699436) (0 likes). Provenance is
  not comprehension. That is the open question.
- **Evidence:** `vendor` + `engagement`.
- **Use.** #5. This is the strongest built version of line-to-conversation provenance so far. A peer
  of Entire and DiffNotes, already cited on that item. **Our own idea** for the test: on one
  accelerate PR authored in a Claude Code session, have HR map each hunk to the transcript turn that
  produced it and count how many decision entries get a real source instead of "not stated". Cost
  unchanged. #6. Per-span thread attribution is the lookup that item needs: a line to the
  conversation that wrote it. The cite is the 2026-11-13 post. The item bodies are unchanged. Open
  PRs insert on lines of both items.

### B. Comprehension debt — #2

- **Post.** [Prayag](https://x.com/Prayag12B/status/2122350982705119490), 2026-11-16. Likes 1,283,
  bookmarks 360, reposts 114, quotes 37, replies 222, impressions 171,444.
- **Claim.** An agent builds a feature, the PR merges, and the developer "only understands 30% of
  what was actually changed". Teams should "measure not just how quickly they ship, but how much of
  their codebase they can still explain". The 30% is the author's illustration, not a measurement.
- **Evidence:** `engagement` only.
- **Use.** #2. Engagement-only demand for a team-level "how much can we still explain" number.
  **Our own idea:** roll #1 quiz scores up per area or directory over time. No cost change. The item
  body is unchanged.
