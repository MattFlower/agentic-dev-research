## Findings

### A. Flyovers — #15 and #17

- **What.** [Flyovers](https://flyovers.dev/), `vendor`. Turns a pull request into an interactive
  video walkthrough in chapters you can jump to: Components, Deployment, Sequence, State machine,
  Implementation care, Code walkthrough, Impact. Those are the 7 chapters on its example PR "Add
  rate limiting to checkout". It "talks you through the change, in an order that makes sense".
  It re-renders on new commits so the walkthrough does not drift from the branch. A link can be
  shared with people without repo access. Public PRs work by pasting a link. A GitHub App adds
  private repos and posts the flyover on the PR.
- **Pricing.** On the page: 50 flyovers a month, unlimited readers, extra flyovers $1 each.
  Launch date not stated on the page.
- **X.** A search for flyovers.dev returned nothing relevant. No engagement found.
- **Evidence:** `vendor`.
- **Use.** #15 (interactive or animated explainer). Chapters are jump targets per owner or area.
  It is narrated video, which conflicts with the backlog's preference for skimmable, code-linked
  text. Worth testing only as the gated #15 view. #17 is the re-render on new commits.

### B. Genesis Map — #7 and #8

- **What.** [Genesis Map](https://github.com/GenesisAgentInfra/genesis). Launch page
  [nowfound](https://nowfound.app/launch/genesis-map-visualize-your-agent-s-changes-see-where-they-ca),
  launched 2026-11-24, 14 votes. Vendor. Open source (Apache 2.0 per X posts). A local CLI and
  skill for Claude Code and Codex. It turns a codebase into a business flow map and flags which
  agent changes are untested or risky. X posts say local only, no model calls.
- **Benchmark.** Author-reported, relayed on X: Claude Code flagged 38% of untested changes with
  it vs 8% without
  ([poweredbymuse](https://x.com/poweredbymuse/status/2125370422225256857),
  [jayjayq8](https://x.com/jayjayq8/status/2125530667564097627)). Unverified. No methodology seen.
  The repo showed 0 stars when fetched.
- **Engagement.** Low. Posts at 0–2 likes on 2026-11-25.
- **Evidence:** `vendor`, plus low `engagement` on the posts above.
- **Use.** #7 (what it's wired into) is the business flow map. That item's body is unchanged. #8
  (test reach) is the flag for changed lines no test reaches. The backlog sentence is on #8.

### C. Kerslake, PRIMM — #1

- **Paper.** Kerslake, "Challenging Novice Programmer GenAI Usage During Code Comprehension Tasks
  with a Predict-Run-Investigate Protocol", Koli Calling '26, published 2026-11-04
  ([doi](https://doi.org/10.1145/3856208.3856264)).
- **What.** Undergraduate intro programming students explain Python code in plain English (EiPE)
  with GenAI, then must predict outputs on test cases and verify by running the code, following
  PRIMM (predict, run, investigate, modify, make) as a productive-failure challenge.
- **Evidence:** `measured-obs`, novice/education sample. Abstract only read. No effect sizes
  quoted.
- **Use.** #1 (comprehension quiz). Supports the existing "at least one output-prediction
  question checked against a run" idea from the 2026-11-13 sweep.

### D. diagram-design — #11

- **What.** [cathrynlavery/diagram-design](https://github.com/cathrynlavery/diagram-design),
  [diagramdesign.dev](https://diagramdesign.dev/). MIT agent skill for Claude Code, Codex,
  Cursor, and others. Draws diagrams as one self-contained HTML+SVG file. 52 diagram types. Can
  import and redraw Mermaid, draw.io, Excalidraw, and PlantUML.
- **Stars.** GitHub showed 72,340 stars when fetched 2026-11-25. On X it was reported trending

- **Evidence:** `vendor` + `engagement` (GitHub stars).
- **Use.** #11 diagram steps. A possible renderer for human-review diagrams instead of Mermaid.
